# 知识测验与前后测评价：教师使用说明

适用网站：https://ai-teaching-assistant.zeabur.app/  
本次测验版本：`infectious-clinical-2026-09-v4`（2026-09-16）

## 1. 课堂使用流程

1. 教师打开网站，在与学生共用的登录页面填写已配置的教师姓名与学号，系统自动识别教师身份并进入管理台；也可从 `https://ai-teaching-assistant.zeabur.app/?admin=true` 进入同一登录入口。无需另设管理密码，也无需完成学生前测。
2. 在“知识测验与学习评价”中点击“查看 A/B 试卷与答案”，正式使用前审阅试题。教师预览含答案，不要投屏给正在测验的学生。
3. 学生首次打开网站填写学号与姓名。其他三个模块暂时锁定，点击“04 知识测验”完成前测。
4. 前测由基础知识20题、皮疹辨别8题、模拟案例8个小题组成，共36小题、100分。全部作答并提交即可解锁学习，**不设置及格门槛**。提交后立即显示总分、三个模块得分、知识维度得分和全部36个小题的解析。每题可点击“去知识问答提问”，自动携带题干、临床背景、作答与参考答案，向知识问答提问。
5. 教师安排知识问答、图谱与临床情景学习。学生以后使用同一学号和姓名登录，系统识别既有前测完成记录，无需重复测试。
6. 到统一后测时间，教师点击“统一开放后测”并确认。所有已经完成前测的学生可在04页面看到“准备开始后测”。页面每30秒检查状态，也可手动刷新。
7. 学生确认开始后测后，本站学习模块及前测解析暂时锁定；提交后恢复。测试中断可继续，但提交后不能修改或重复作答。
8. 完成后测后，学生可以查看前后测成绩、各知识维度得分和逐题解析。教师可导出配对成绩、逐题作答。
9. 教师点击“关闭后测入口”只阻止**新的后测开始**，已经开始的后测可以继续完成。

后测是否开始由教师开放状态和学生确认共同决定，不按学习时长自动开放。当前开放范围是整个网站，不分班级。

教师可以直接使用三个学习模块，并在管理台审阅两套试卷；教师账号不参加学生前后测，也不会计入学生人数、成绩和学习访问统计。教师的姓名与学号由服务器环境变量 `TEACHER_NAME` 和 `TEACHER_STUDENT_NO` 配置，不写入公开网页脚本。只改前端角色或网址不能取得教师权限。

## 2. 两套试卷如何配对

| 部分 | 题量 | 单题分值 | 小计 | 预设难度 |
|---|---:|---:|---:|---|
| 一、基础知识 | 20题 | 3分 | 60分 | 基础8题、应用8题、综合4题 |
| 二、皮疹辨别 | 8题，前4题文字、后4题配图 | 2分 | 16分 | 形态识别与临床鉴别 |
| 三、模拟案例 | 2个案例，各4个单选小题 | 3分 | 24分 | 临床应用1例、综合决策1例 |
| 合计 | 36个作答点 | — | 100分 | 梯度递进 |

每个小题仅有一个最佳答案，答对获得该题全部分数，答错0分，不倒扣分。每个案例的四个小题分别考查诊断、检查、治疗和病情变化后的连续决策，合计12分。各节编号独立，模拟案例的小题在每个病例内从1开始。

题库依据现有知识库中的病种与知识点编写，不在测验时临时调用AI生成或由AI打分。候选池包含25组配对知识题（每组A、B各一道），围绕临床识别与鉴别、病原学与检验判读、病情分层、治疗及疗效监测设计，覆盖猴痘、麻疹、病毒性肝炎、发热伴血小板减少综合征、布鲁氏菌病、乙脑、细菌性痢疾、疟疾、肺结核、水痘、百日咳、登革热、禽流感和流感等。新版不把社区防控、健康宣教或人群管理作为独立测验考点。

系统在首次初始化时按难度分层随机抽取20组知识点，并同时生成A/B两卷。**全批次使用同一知识点蓝图，不给每位学生独立抽取不同病种**，以保持前后及学生间的可比性。两卷知识点、分值和预设难度一致，设问及病例不同。每位学生随机分配A→B或B→A顺序，选项排序再次随机，减少固定卷序和固定答案位置的影响；随机分配不保证小样本人数完全相等。

两道案例依据原有登革热、肺结核训练目标改编，更换年龄、职业、病史和临床资料，不直接复制训练病例。病例正文不直接标明疾病；检查与治疗仍需结合临床知识作判断，不能理解为完全消除所有医学线索。

题目、答案、知识点ID、依据文档与URL保存于服务器。未提交试卷不返回答案、解析或隐藏的知识点标签；前测提交后立即开放本人的成绩和解析。后测开始后，解析接口暂时受限，提交后恢复两次试卷的完整反馈。

基础知识及案例沿用上一版本重写的临床题库，本版新增16道A/B配对皮疹题。选项尽量采用同类诊断、检查、疗程或药物，减少“仅凭”“无需”“唯一依据”等语气提示，补充病程、器官功能、药物敏感性或特定方案等必要条件。保留有效医学线索，不以模糊临床信息人为增加难度。两卷继续按相同知识点、分值和预设难度配对，难度等值性仍需教学预测试检验。

### 二、皮疹辨别：配对设计与图片使用

“02 皮疹图谱”已移除独立小测验，恢复检索、筛选、详情、并排鉴别等浏览功能；皮疹辨别统一进入正式前后测，计入100分。前4题为纯文字的水痘、带状疱疹、猩红热和二期梅毒辨别；后4题为麻疹、风疹、猴痘和手足口病图片辨别，结合临床资料与皮损图像选择最佳诊断。题干不使用“模拟病史”标签，也不加入用药史作为提示。图像观察不等同于病原学确诊，解析会说明必要的确认方法。

A/B卷的8个考点、分值和预设难度逐题对应，但病例及设问不同；同病种配图题选用图谱中不同图片。所有图片复用图谱已有资源和出处，不使用AI合成皮损。图片可点击放大，加载失败可重试，未成功加载图片时页面阻止提交。答题前图片URL与替代文本不含病名，接口不返回答案或诊断性图注；提交后展示解析及图片来源、许可和链接，教师预览也可审阅完整信息。开始后测后不能通过前测图片接口回看。

图片均来自已收录的CDC PHIL公有领域资源或PMC开放许可文章。A/B卷采用不同图片，并不意味着视觉难度已经严格等值，需教师审核清晰度、典型程度和临床背景一致性。

## 3. 导出内容与解释

**配对成绩CSV：** 学号、姓名、卷序、前后测状态与成绩、提升分、两次测验间隔、学习模块访问次数、两次测验用时、版本，以及前后测各自基础知识、皮疹辨别、模拟案例的得分与满分。旧卷不含皮疹辨别时该模块留空，不按0分处理。

**逐题作答CSV：** 学号、姓名、阶段、卷别、配对知识点ID、知识点、疾病、难度、题号、题干、所选答案、正确答案、得分、满分、开始与提交时间戳、试卷版本、测验模块、题目形式和图片出处。两卷请使用“配对知识点ID”匹配，不要按选项字母匹配。

- 提升分 = 后测总分 − 前测总分，范围−100至100。
- 后台平均分变化仅纳入已完成两次测验的学生，不把缺失后测当0分。
- 用时 = 提交时间 − 开始时间，包含离开页面或中断时间，**不是有效作答时间**。
- 学习间隔 = 后测开始 − 前测提交，**不是有效学习时长**。
- 模块访问次数是页面进入次数，刷新或重复进入可能增加。不是提问次数、阅读质量、停留时长或认真学习的证明。
- 文件使用UTF-8 BOM，Excel可直接打开。CSV公式起始字符进行了转义。导出含可识别学生信息，应按学校规定存储；做研究分析宜先另建匿名编号并去标识化。

## 4. 正式教学评价前的审查

这两套试卷是按共同蓝图设计的**平行卷初稿**，不是已经完成心理测量学验证的等值量表。建议任课教师进行内容效度审查，再做小样本预测试，检查难度、区分度、内部一致性、A/B卷差异及前后测天花板效应。基础题干扰项相对容易识别，若学习者原有水平较高，应在正式招募前提高难度并生成新的测验版本。

若用于正式研究，请先明确研究说明、知情同意/伦理审查要求、数据管理责任人与保存期限，并统一学习任务、测验时间安排、独立作答要求。单组前后测成绩提高可能同时受到练习效应、熟悉题型、其他学习经历及选择偏倚影响，**不能单独证明AI工具造成了提升**。拟作因果推断时应另行设计适当对照与分析方案。随机A/B卷序只减少卷序影响，不代替研究对照组。

本版按教学要求开放前测即时解析。因此后续成绩变化包含“前测反馈复习＋AI教学工具学习”等共同作用，前测反馈已成为学习干预的一部分。比较班级或组别时应统一反馈可见性与学习安排，并在研究方法中记录这一点。

本版本按用户要求，学生和教师都仅用学号和姓名登记登录。这两项通常不是秘密，**不能防止知道他人信息的人冒用身份；知道指定教师姓名与学号的人也可能取得管理权限**。该方式仅适合受控课堂，不适合作为高风险考试或正式敏感数据系统的强认证。正式考核应另接学校统一身份认证或增加额外验证。网站不能阻止学生在其他设备或外部页面查询资料，不能替代监考。

## 5. 数据保存与运维

- 生产环境使用Zeabur持久卷 `/data`，数据库为 `/data/study.sqlite3`，不会打包进镜像或Git。
- 本地开发默认使用 `var/study.sqlite3`；测试服务器使用独立临时目录，不应把测试数据库上传到生产。
- 生产环境设置 `STUDY_DATA_DIR=/data`、`STUDY_REQUIRE_VOLUME=true`，未挂载持久卷时拒绝测验服务，避免误将正式成绩存入临时容器文件系统。
- 登录会话为HttpOnly、SameSite=Lax Cookie；HTTPS下设置Secure，30天有效。服务器保存会话令牌的哈希，不在浏览器本地保存成绩或答案密钥。
- 服务器同时执行前测解锁、后测开放与作答权限检查。页面隐藏不是唯一权限控制。
- 草稿自动保存并使用版本号处理多窗口冲突，最终提交在数据库事务中判分；同一学生同一阶段只能有一次正式提交，重复请求不会重复计分。
- 不要在同一学号下同时用多个窗口作答。如提示“其他页面已更新作答”，先确认另一窗口内容，再刷新载入服务器最新进度；不要通过清浏览器缓存试图重做测验。
- A/B卷按版本冻结。题库升级会生成新的当前版本；已经开始旧版前测的学生仍会取得与其前测版本匹配的旧版后测，避免跨版本比较。本次更新不删除或改写已有作答。即时反馈也适用于此前已提交的前测，但解析内容使用该次冻结试卷。
- v4新增皮疹辨别并调整模拟案例分值；已开始的旧28题卷仍保持原来60/40计分，新开始的测验使用36题60/16/24计分。跨版本成绩不能直接视作同一测量工具，应按版本分别分析。旧独立图谱小测验的入口与接口已移除，历史数据库记录不作破坏性清除。
- 定期导出成绩并通过Zeabur备份能力或SQLite在线备份API备份数据库。持久卷不等于异地备份；不要只复制运行中的主数据库文件而遗漏WAL。备份应限制访问并遵循学校保存期限。
- 学号填错、姓名更正、退出研究或删除请求目前由教师联系管理员核实处理。没有开放学生任意修改/删除成绩的接口。
- SQLite部署应维持单服务实例，避免多个副本各写不同磁盘；大规模并发或多校场景应迁移集中式数据库。

## 6. 医学依据与核对

各题内部保存知识库原始条目ID和依据文档；教师A/B预览显示依据文档，服务器保留源URL。题目避开具体个体处方和不必要的精细剂量记忆，主要考查临床识别与鉴别、检查选择和结果解释、病情分层、治疗及动态监测。

本次另外核对了以下公共卫生机构资料：

- CDC：[登革热临床管理](https://www.cdc.gov/dengue/hcp/clinical-care/index.html)，用于核对警示征象、监测与补液原则。
- CDC：[结核临床及实验室诊断](https://www.cdc.gov/tb/hcp/testing-diagnosis/clinical-and-laboratory-diagnosis.html)，用于核对痰分子检测、培养与耐药评估。
- CDC：[重症疟疾治疗](https://www.cdc.gov/malaria/hcp/clinical-guidance/iv-artesunate-us.html)，用于核对注射用青蒿琥酯及后续完整疗程的原则。
- WHO：[猴痘专题](https://www.who.int/health-topics/mpox)，用于核对临床表现与病原学检测背景。

2026-09-15修订另外核对：

## 7. 验证方式

自动检查：`python -m unittest discover -s tests -q`。

本机端到端验收：启动 `PYTHONPATH=. python tests/run_study_server.py` 后运行 `tests/browser_study.cjs` 和 `tests/browser_case_training.cjs`（需Playwright及Chrome）。该服务器使用模拟AI和临时数据库，浏览器测试拦截知识问答流式请求并提供固定测试回答，**不要部署到生产**。
